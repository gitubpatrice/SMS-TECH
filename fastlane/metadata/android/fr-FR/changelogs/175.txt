Mode panique enfin utilisable.

Le second code qui ouvre l'app en mode leurre — coffre et mode urgence invisibles — était annoncé mais n'avait aucun écran de réglage. Il se configure désormais dans Réglages, Sécurité.

Écran de verrouillage : un code erroné le dit maintenant en rouge, et le blocage après trop de tentatives se lève bien à la fin du décompte.

Les envois programmés transportent enfin leurs pièces jointes : photo et texte partent ensemble à l'heure prévue.
